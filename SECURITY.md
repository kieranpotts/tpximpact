# Security policy

## Supported versions

Security fixes are issued only for the versions listed below. Older releases
receive no patches, and users are expected to upgrade.

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: |

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests. Public disclosure before a fix is available puts
every user of this project at risk.

Instead, use GitHub's private vulnerability reporting: go to the **Security**
tab of this repository and choose **Report a vulnerability**. If that is
unavailable, email <hello@kieranpotts.com> instead.

Include as much of the following as you can. It all helps to triage the report
more quickly:

- The type of issue, and the version or commit in which you found it.
- The paths of the affected source files.
- Any special configuration required to reproduce the issue.
- Step-by-step instructions to reproduce it.
- Proof-of-concept or exploit code, if you have it.
- The impact of the issue, including how an attacker might exploit it.

## What to expect

- **Acknowledgement within 3 working days.** If you do not hear back in that
  time, please follow up — the original report may not have arrived.

- **An assessment within 10 working days**, covering whether the report is
  accepted, the severity assigned to it, and the expected remedy.

- **Progress updates** at least every 14 days until the issue is closed.

Reporters who want credit will be named in the advisory published alongside the
fix. Tell us how you would like to be credited, or say if you would rather stay
anonymous.

This project does not operate a paid bug bounty.

## Disclosure

Accepted vulnerabilities are fixed and disclosed through a
[GitHub security advisory](https://docs.github.com/en/code-security/security-advisories),
which requests a CVE identifier where one is warranted. The advisory is
published once a fix is released, or after 90 days from the original report,
whichever comes first.

Please keep the report confidential until the advisory is published.
