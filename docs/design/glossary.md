# Glossary

Architecture- and domain-specific terms used across all the architectural views.

> [!IMPORTANT]
> The domain and architectural terms defined in this glossary MUST be used
> consistently throughout the code, tests, docs, and all other artifacts in this
> repository. Do not introduce synonyms or alternative names for a defined term.

- **Alias** \
  The path segment that identifies a short URL, for example `my-alias` in
  `http://localhost:8080/my-alias`. It's case-sensitive.

- **API service** \
  The Kotlin service that implements the OpenAPI specification. Owns all
  business rules, and performs redirects.

- **API base URL** \
  The internal address the web client uses to call the API
  (`API_BASE_URL`). Not to be confused with the *public base URL*.

- **API client** \
  Any program that calls the API directly, rather than through the web
  client, for example `curl`.

- **BFF (back-end for front-end)** \
  A server-side component dedicated to one user interface, which calls
  back-end APIs on the browser's behalf. The web client is a BFF.

- **Custom alias** \
  An alias chosen by a link creator, supplied via the `customAlias` field.

- **Database** \
  The PostgreSQL database that holds the `short_url` table. Only the API
  reads and writes it.

- **Destination URL** \
  The destination a short URL redirects to, supplied via the `destinationUrl`
  field.

- **Link creator** \
  A person who shortens, lists, or deletes URLs using the web client.

- **Link visitor** \
  A person, or crawler, who follows a short URL.

- **Problem details** \
  The JSON error format from RFC 9457 (`application/problem+json`), used for
  every API error response.

- **Public base URL** \
  The absolute URL that prefixes every short URL (`PUBLIC_BASE_URL`), as
  link visitors see it.

- **Random alias** \
  An alias generated by the API when no custom alias is supplied. Consists of
  seven Base62 characters.

- **Reserved alias** \
  A word that can't be used as an alias, because it is (or may become) an API
  route, for example `urls`.

- **Short URL** \
  The public base URL followed by `/` and an alias. It is the `shortUrl` field
  in the API contract. It's computed when needed, and not stored whole (only the
  alias part is persisted).

- **Web client** \
  The Express application that serves the HTML user interface.
